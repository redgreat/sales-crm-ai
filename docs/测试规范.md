## 3. 标准联调命令

```bash
# 前置：CRM 实例 + AI 服务已就绪，token 已取
# M-03 助手建档端到端（真实模型 + 真实写入；3 用例约 1 分钟）
SAI_CRM_BASE_URL="http://127.0.0.1:18080/api/v1/salescrm" \
  .venv/Scripts/python.exe -m pytest tests/test_p4_draft_live.py -q -m draftlive

# AI→CRM 事实查询 HMAC 联调（9 场景，不需要 JWT；不要频繁跑，注意额度）
.venv/Scripts/python.exe scripts/crm_facts_live_check.py \
  --base-url http://127.0.0.1:18080/api/v1/salescrm --key-id crm-ai --secret <见 application-dev.yml>

# OCR/ASR POC（4.13 已通过不再跑 OCR——200 次/月额度留给生产；ASR 额度 36000 秒）
.venv/Scripts/python.exe scripts/ocr_poc.py
.venv/Scripts/python.exe scripts/asr_poc.py [--audio-url 公网URL]
```

## 4. 测试数据注意事项

- 联测数据统一前缀（`联测客户-`/`联测线索-`）+ uuid 后缀；重复运行会触发 CRM 名称/内容相似查重，
  测试的 confirm 调用带 `similar_continue_reason`（「AI 联测数据，确认为新客户/线索」）。
- 正式对象写入是**真实的**（zrcrm 库）：测试产生的客户/线索为联测垃圾数据，定期清理由人工负责。
- 服务器间 HMAC 密钥见 CRM `application-dev.yml`（key-id `crm-ai`）；AI 侧同值在 `conf/config.yml` `auth.*`。
- OCR 免费额度 200 次/月——**POC 已通过，日常不再跑 OCR 真实调用**。
