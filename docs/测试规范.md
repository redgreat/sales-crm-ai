## 2.0 多智能体并行端口分配（避免实例互撞）

多个智能体同时联调时，默认端口留给先占者，后来者/并行任务一律改用备用端口：

| 智能体 | CRM Java | AI 服务 | H5 联调端 | 说明 |
|---|---|---|---|---|
| 主车道（Codex/默认） | 18080 | 8310 | 8320 | 上表标准端口 |
| 并行任务（ZCode） | **18082** | **8311** | 8321 | CRM：`--server.port=18082`；AI：`SAI_CONFIG` 指向副本配置或改 `api.port`；H5：`--port 8321 --crm-base http://127.0.0.1:18082/api/v1/salescrm` |

- 启动前先 `netstat -ano | grep <端口>` 确认空闲；**不要停别人的实例**，只 stop 自己启动的进程。
- jar 锁定：某端口实例运行期间不能 clean 同一 target 目录的包；并行构建请用独立 worktree。
- HMAC 凭据各端口同源（crm-ai + AI_SERVICE_AUTH_SECRET），换端口不需要改签名配置。

## 2.1 H5 联调端登录（不再手工粘贴 token）

```
.venv/Scripts/python.exe scripts/h5_server.py --port 8320 --open
```

- 页面填工号/密码点「登录」→ 服务端完成 password grant，token 写入 `.local/crm-token.txt`，
  OAuth `client_secret` 不出本机、不进浏览器；勾选「保持登录」后密码只保留在服务进程内存中，
  token 临近过期（剩余 <120s）自动续期。页面不把密码写入 localStorage 或其他磁盘存储。
- 已有未过期 token 时页面载入即自动复用，或点「复用本机 token」。
- 页面所有请求走同源 `/crm/**`，由脚本代理到 CRM 并注入 `Authorization`：
  CRM 的 CORS 白名单只有 `localhost:81`（`MvcConfiguration`），**直接双击 index.html（file://）会被浏览器拦截**。
- 凭据来源优先级：`SAI_CRM_CLIENT_SECRET` 环境变量 → `.local/identity.json` → `scripts/get_crm_token.py` 常量。
  脚本本身不含密钥，已入库；`get_crm_token.py` 含 secret 保持 ignore。
- 应急通道：页面「手动 token」可粘贴已有 JWT（不推荐，走 `/__login` 的 `{"token": ...}`）。

### 2.1.1 随镜像部署的 H5 联调页（`/h5`）

同一页面由 AI 服务内置提供（代码在 `app/devtools/h5`，测试面、与业务代码隔离）：

- 地址：`https://<AI 域名>/h5`（反代把 `/h5` 原样透传到容器 8310 即可，不需要额外端口/进程）。
- 前置：AI 服务 `environment` 为 dev/test 且 `api.playground.enabled: true`；prod 下 `/h5` 一律 404。
- 登录凭据：配置后台「外部接口 → CRM 接口」填写 `base_url`（CRM API 前缀）与凭据 `client_secret`；
  `token_endpoint`/`client_id`/`scopes` 有默认值，一般不用改。登录（OAuth 密码授权）在服务端完成，
  token 只存进程内存，容器重启即失效，重新用工号密码登录即可。
- 页面调用走同源 `/h5/crm/**`，由服务代理到 CRM 并注入用户 JWT，因此不受 CRM CORS 白名单限制。
- 本地继续用 `scripts/h5_server.py`（根路径托管）亦可，两条路径语义一致。

## 4. 测试数据注意事项

- 联测数据统一前缀（`联测客户-`/`联测线索-`）+ uuid 后缀；重复运行会触发 CRM 名称/内容相似查重，
  测试的 confirm 调用带 `similar_continue_reason`（「AI 联测数据，确认为新客户/线索」）。
- 正式对象写入是**真实的**（zrcrm 库）：测试产生的客户/线索为联测垃圾数据，定期清理由人工负责。
- 服务器间 HMAC 密钥见 CRM `application-dev.yml`（key-id `crm-ai`）；AI 侧同值在 `conf/config.yml` `auth.*`。
- OCR 免费额度 200 次/月——**POC 已通过，日常不再跑 OCR 真实调用**。
- `tests/test_crm_integration.py` 与 `tests/test_p4_draft_live.py` 的真实写入用例都必须显式设置 `SAI_RUN_CRM_LIVE=1` 且有有效 JWT；本地过期 token 文件不会自动启用测试。运行前确认 Java 目标实例、测试账号和正式业务写入窗口。
