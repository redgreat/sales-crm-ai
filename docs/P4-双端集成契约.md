## 1. 事实查询（AI → CRM，HMAC 服务签名）

| 项 | 冻结值 |
|---|---|
| 方法/路径 | `GET /api/v1/salescrm/ai/integration/facts/{subjectType}/{subjectId}` |
| subjectType | `customer` / `lead` / `opportunity`（0.1 三种；未知类型 CRM 返回 400，**不静默 found=false**） |
| 保护 | `AiServiceSignatureFilter`（HMAC），免 JWT（`ignore-url` 已含 `/ai/integration/**`） |
| 签名 path 口径 | **完整 URI path（含应用前缀）**：`/api/v1/salescrm/ai/integration/facts/...`。Python 客户端从 `crm.base_url` 提取前缀拼接；Java 验签用 `request.getRequestURI()`。两侧逐字段一致（见 §3） |
| 响应（found） | `{"subject_type","subject_id","found":true,"facts":{...}}` |
| 响应（不存在） | `{"subject_type","subject_id","found":false,"facts":{}}`——CRM 不造默认值，降级由 AI 决定 |
| facts 字段 | customer：id/name/customer_code/customer_type/value_level/master_status/industry；lead：id/lead_code/contact_name/biz_status/owner_id/owner_name/biz_line_name/region_name/next_action；opportunity：id/opp_code/name/customer_id/customer_name/stage_name/process_status/close_result/owner_name/expected_close_on |
| 错误 | 401 签名失败；400 未知类型/空 id；权限不足按 CRM 数据范围规则（本人可见范围） |

Python 侧客户端：`app/integrations/crm.py::HttpCrmFactsClient`。`crm.base_url` 必须含应用前缀
（如 `http://127.0.0.1:8080/api/v1/salescrm`）。

## 2. Run 代理与候选链（CRM → AI，JWT 用户身份；AI 侧 HMAC 验签）

| 步骤 | 调用 | 说明 |
|---|---|---|
| 代理创建 | `POST {ai}/api/v1/runs`（capability=communication.extract） | CRM `AiRunClient`；**幂等键必须稳定**（AI 侧 ≥8 位，重复提交返回原 Run） |
| 查询/等待 | `GET /api/v1/runs/{id}`、`GET /api/v1/runs/{id}/pending` | pending 返回 questions + state_version |
| 补参恢复 | `POST /api/v1/runs/{id}/resume`（state_version + values） | 版本不匹配 409；会话关闭/过期一律拒绝 |
| 结果拉取 | CRM 侧 `importRunResult`：`GET /api/v1/runs/{id}` 取 result | 服务端拉取保证来源可信；重复导入返回已有候选（`(ai_run_id, item_id)` 唯一） |
| 确认 | CRM `/runs/{runId}/confirm`（items 逐条 override） | 先活动后任务；活动失败派生任务停止；逐条独立写入允许部分成功 |
| 失败重试 | CRM `/runs/{runId}/retry` | 沿用原幂等键，重试前重新校验 |

**AI 侧验签口径**：`deps.require_operator` 用 `request.url.path`（完整，含 `/api/v1`）——CRM 出站签名
path 已是完整路径，两侧一致（此前 401 的根因之一）。

## 3. HMAC 签名（双端一致，`app/auth.py` ≍ `AiHmacSigner`）

签名串按 `\n` 连接 7 段：`key_id、METHOD（大写）、path（query 之前、含应用前缀）、timestamp（unix 秒）、nonce、operator_user_id、body_sha256_hex`；
空 body 取空串 sha256。算法 HmacSHA256 hex。头：`X-SAI-Auth: SAI-HMAC-SHA256`、`X-SAI-Key-Id`、`X-SAI-Timestamp`、`X-SAI-Nonce`、`X-SAI-Signature`、`X-SAI-User-Id`、`X-SAI-User-Name`（百分号编码）。时间窗 ±300s，nonce 防重放（AI 侧持久化、CRM 侧进程内）。
